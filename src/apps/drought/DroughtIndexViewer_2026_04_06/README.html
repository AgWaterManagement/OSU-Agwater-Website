Oregon Drought Index Viewer

This directory contains the React-based web application for the Oregon Drought Index Viewer. The tool presents agricultural, meteorological, and hydrological data using interactive maps and charts.

Architecture

The application is built using reusable React components. This modular approach separates the different parts of the interface—such as the map, the data summary panel, and the historical charts—into their own isolated files. This structure allows the interface to update automatically whenever a user selects a new basin or changes a setting.

Build System

This project uses Vite as its build tool.

Vite provides a local development server. When changes to the code are made, Vite updates the application in the browser without requiring a full page refresh. When it is time to deploy, Vite bundles the code into production-ready files.

Running Locally

To run the web interface on your local computer:

  1. Open a terminal and navigate to the drought_index_react directory.
  2. Install the necessary dependencies and start the local server by running: 
    npm install
npm run dev
  3. Open your web browser and navigate to the localhost address provided in the terminal.

Technology Stack

  • Framework: React 19
  • Data Engine: DuckDB-WASM (analyzes datasets directly inside the browser)
  • Maps: React-Leaflet
  • Charts: React-Plotly.js
